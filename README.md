# cv-forge

把真实经历「锻造」成有说服力、可投递简历的 AI Skill（WorkBuddy / Claude Code 均可用）。专注内容质量，不做排版模板。

> 不帮你把空话写得更漂亮，而是帮你把经历写得更有分量。

## 核心流程

诊断 → 追问 → 重写 → 自检 → 迭代

- **三档意图路由**：快车道（单段改写）/ 标准锻造（完整闭环）/ 深度审计（全卷诊断），按用户意图匹配，不强制走长流程
- **两种模式**：通用优化 / 按 JD 定制（关键词对齐、项目重排、侧重调整）
- **硬性原则**：不编造数据、不过度包装、保留真实语气、敢删减

## 场景支持

校招 / 实习 / 社招 / 海外。场景作为配置项自动识别或一键确认，中文求职特有问题（培训班项目、注水经历、外包背景、一页纸压缩）有专门处理策略。

## 使用

将本仓库作为 skill 安装（`SKILL.md` + `references/`），对 AI 说"帮我改简历"即可触发。

## 结构

```
SKILL.md                     # 主流程：意图路由 + 锻造闭环 + 硬性原则
references/
├── diagnosis.md             # 诊断 rubric（含复检指标）
├── rewrite.md               # 职责→成果改写、反模板化、删减优先级
├── jd-alignment.md          # JD 拆解、关键词对齐、变更说明表
└── scenarios.md             # 校招/社招/海外差异与高频雷区
```
