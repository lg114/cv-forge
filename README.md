# CV Forge

CV Forge 是一个简历优化 Skill：在不虚构、不夸大事实的前提下，整理简历结构、改进表达，并按目标岗位突出已有的相关经历。

## 快速开始

把简历或经历事实发给 AI 工具，并说明你希望怎么优化。目标岗位、优化力度、篇幅和交付格式都可以选填；未指定时会按默认设置开始处理。

```text
请按以下 JD 优化我的简历，标准力度，目标一页。

【简历】
…

【JD】
…
```

也可以只贴简历，或用要点清单描述经历。没有 JD 时会先做通用优化，你可以之后再补充岗位信息。

## 你会得到什么

- 一份完整的优化简历，默认以 Markdown 输出。
- 一份修改说明，列出改写内容、建议补充的信息，以及刻意保留的内容和原因。
- 每条经历要点带定位号，方便在后续对话中指出要修改的位置。
- 有 JD 时附简洁的对齐说明，展示简历中已有的相关证据和待补事实；不提供匹配分数。

只有明确要求 PDF 时才会生成 PDF，并在交付前渲染检查。PDF 使用简洁的单栏版式，不含仅用于对话定位的编号。

## 使用方式

**按 JD 优化**

```text
请按以下岗位描述优化我的简历，标准力度。

【简历】
…

【岗位描述】
…
```

**从经历要点整理简历**

```text
请根据以下事实整理一份简历，不要补充我没有提供的信息：
- 2022–2024，XX 公司，后端开发
- 参与订单系统重构；项目 QPS 从 500 提升到 2000
```

**多轮修改**

```text
把简历第 3 条改成强调团队协作；第 5 条的结束时间应为 2023.06。
```

后续可以补充 JD、修正事实或调整偏好。局部反馈只更新相关内容；调整全局偏好时，可能需要重新检查整份简历。

## 工作边界

- 只组织和改写用户提供或确认的事实，不编造经历、数字、技能或职责。
- 不提供简历评分、岗位匹配分数、复杂排版设计或多版本对比。
- 默认输出 Markdown；PDF 需要明确提出。
- 默认目标篇幅为一页。若按当前优化力度无法合理压缩，会列出候选内容供你决定。

完整流程与规则见 [SKILL.md](SKILL.md)；各操作规范见 [`references/`](references/)。

## 安装

将仓库下载到本地，再按所用 AI 工具的说明导入 Skill。导入目录需包含 `SKILL.md` 和 `references/`。无需额外依赖或构建步骤。
