# cv-forge

把真实经历「锻造」成有说服力、可投递简历的 AI Skill。
专注**内容质量**，不做排版模板。

> 不帮你把空话写得更漂亮，而是帮你把经历写得更有分量。

适用于 WorkBuddy / Claude Code 等支持 Agent Skills 的环境。

## 它解决什么问题

多数简历的问题不在排版，而在：

- 职责说明书式的空话（「负责… / 参与…」）
- 没有量化、没有结果
- 不会按岗位调整侧重
- 写完没人挑刺，也不敢删

cv-forge 按「诊断 → 追问 → 重写 → 自检 → 迭代」闭环处理这些内容问题。

## 核心能力

| 能力 | 说明 |
|------|------|
| **三档意图路由** | 快车道（只改一段）/ 标准锻造（完整闭环）/ 深度审计（全卷诊断）。按意图匹配，不强制走长流程 |
| **通用优化 / JD 定制** | 无 JD 时拉高质量；有 JD 时先拆解再对齐，输出变更说明表 |
| **诚实处理雷区** | 不编造数据、不帮注水项目伪装；外包 / 培训班 / 空窗给真实表达方式 |
| **中文求职场景** | 校招 / 实习 / 社招 / 海外可配置；一页纸压缩、关键词对齐有专门规则 |

**硬性原则**：不编造 · 不过度包装 · 保留真实语气 · 敢删减

## 快速开始

1. 将本仓库作为 skill 安装（需包含 `SKILL.md` + `references/`）
2. 对 AI 说一句触发语，例如：

```
帮我诊断一下这份简历有什么问题
```

```
只改 RagMate 这一段，别动其他部分
```

```
按下面这份 JD 定制优化简历，给出变更说明表
（贴 JD）
```

```
按标准锻造流程重写，并给出 before/after 和复检指标
```

## 仓库结构

```
SKILL.md                     # 主流程：意图路由 + 锻造闭环 + 硬性原则
references/
├── diagnosis.md             # 诊断 rubric（含复检指标基线表）
├── rewrite.md               # 职责→成果、反模板化、删减优先级
├── jd-alignment.md          # JD 拆解、关键词对齐、变更说明表
└── scenarios.md             # 校招/社招/海外差异与高频雷区
```

主文件保持轻量，细则按需加载，避免每次触发都塞满上下文。

## 不做什么

- 不做视觉排版 / 模板美化
- 不虚构经历、数字或技术栈
- 不把个人项目包装成「企业级」或伪造工作年限
