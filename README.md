# CV Forge

轻量简历优化 Skill：在**不虚构、不夸大事实**的前提下，优化简历的结构完整性、措辞准确性与岗位针对性，输出改进后的完整简历及结构化修改说明。

规则细节以 [SKILL.md](SKILL.md) 为准，本文件只做导航。

## 核心能力

- **输入**：纯文本、Markdown 或结构化字段；可选提供目标岗位 / JD、优化力度（轻度 / 标准 / 深度）、语言风格、目标市场
- **流程**：结构解析与完整性检查 → 措辞优化 → 针对性诊断 → 生成优化简历 + 结构化修改说明
- **输出**：完整优化简历 + 修改说明（改了什么、为什么改、哪些未动及原因）
- **迭代**：基于上一轮结果的简单多轮修订，已认可的部分逐字不动

## 不做的事

简历评分、岗位匹配打分、排版模板设计、多版本生成、行业深度研究、从零虚构代写。

## 安装

将本目录（`SKILL.md` 所在处）导入为 Skill 即可，无其他依赖。
