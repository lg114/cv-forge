# JD 对齐矩阵规范

仅当用户提供 JD 时建立。矩阵用于解释已做的定向动作和暴露事实缺口，不用于评分、排名或预测录用结果。

## 行的构成

每一行只包含一项可执行的 JD 要求：

| 字段 | 规则 |
|---|---|
| JD 要求 | 逐字摘取或忠实压缩成一个能力、技术、职责或硬性条件；不把偏好改成硬要求。 |
| 简历证据 | 引用对应事实账本 ID；没有证据就明确写「未见可用证据」。 |
| 处理 | 仅可为「前置」「等义换词」「保持」「建议补事实」或「不适用」。 |

同一事实可以支持多项 JD 要求，但不能因此重复写进简历。一个 JD 要求没有证据时，只能进入「建议补事实」，不因关键词相似就视为满足。

## 对外交付

交付时只展示对用户决策有用的精简行：已采取定向动作、关键硬缺口，以及容易被误认为已满足的要求。避免逐句复述冗长 JD；不展示内部优先级、权重或分数。
