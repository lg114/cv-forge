# 措辞规范

改写每条内容时用的操作标准。**规则与边界以 SKILL.md 为准**——本文件只提供可照抄的对照表，不另立规则，也不放宽 SKILL.md 第 2 步的事实红线。

## 动词与成果强度分档

同一个动作可以用不同强度的词描述。**用哪一档由素材依据决定，不由期望决定**：改写前先定位素材能支撑的档位，只允许使用该档及以下的动词。

| 档 | 典型动词 | 用这一档的前提（须能在原文或用户确认中找到） | 不满足时 |
|---|---|---|---|
| 1 协助 / 参与 | 参与、协助、配合、支持 | 能指出本人在其中交付的**具体产物**，哪怕很小 | 连产物都说不出 → 只写本人做过的动作，不写这段经历的整体结果 |
| 2 负责 / 执行 | 负责、完成、实现、开发、编写、独立完成 | 能指出**范围边界**：这件事由本人交付，并能说出范围多大 | 说不出边界 → 降回第 1 档 |
| 3 主导 / 牵头 | 主导、牵头、推动、重构 | 能指出本人是**决策者**（方案由本人定 / 资源由本人协调），并能说明**协作规模**（几人、哪些角色） | 说不出决策权或协作规模 → 降回第 2 档 |
| 4 从 0 到 1 / 定义 | 从 0 到 1 搭建、定义、建立 | 能指出**此前不存在**，并能说明建成后的使用范围 | 说不出「此前没有」→ 降回第 3 档；说不出使用范围 → 降回第 2 档 |

**四条纪律**

1. **只能降档，不能跳档。** 素材只支撑第 1 档时，不能因为想写得漂亮就跳到第 3 档——与 SKILL.md 第 2 步事实红线同源，不是本文件另立的规则。
2. **同一条 bullet 内部必须同档。** 动词说「主导」，同一句里却没有任何范围或协作信息，读的人会立刻感到不匹配。动词强度要与句子其余部分的信息量一致。
3. **同一段经历的不同 bullet 可以处在不同档，整段不能统一升档。** 人倾向于把整段经历按最高档描述，这是最常见的夸大来源。
4. **团队成果有上限。** 账本里 `owner` 为团队时，动词可以描述本人做的动作，但不能用第 3、4 档描述结果；结果归属见 [事实账本规范](fact-ledger.md)。
