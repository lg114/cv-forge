# 多轮迭代

**原则**：按用户反馈更新完整简历，尽量保留已确认内容。每轮输出修订后的**完整简历**（不是 diff）+ **本轮增量修改说明**（只列本轮改动）。

以下四类反馈按各自范围处理：

1. **补充 JD**：只重跑第 3 步（针对性调整）+ 重新评估「总体判断」，已确认措辞不重改。两处例外：JD 等义换词（第 3 步允许，需标注）；上轮无岗位信息、本轮才拿到 JD 时，允许在力度档内重新排序——需跨档则列为「建议」。不删要点、不删经历段、事实与措辞骨架不动
2. **改全局偏好**（语言风格 / 目标市场 / 目标篇幅）：影响全篇，重新过第 2 步措辞优化或按篇幅预算重新取舍；事实骨架、结构、已确认的针对性调整不动
3. **修正事实**（改时间、补数字、回答「高价值待确认」）：直接采信用户口径，写入事实账本，只重生成受影响的段落
4. **明确要求重做**（「全部重来」「按新标准重新优化」）：唯一的全局重跑出口，从第 1 步重跑全流程，修改说明从零计
